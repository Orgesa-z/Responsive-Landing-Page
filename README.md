# Morrow — Responsive Landing Page

A beginner-friendly landing page concept for Morrow, a fictional collaboration tool for small teams. Built with plain HTML, CSS, and JavaScript.

## Open the site

Open `index.html` in a web browser. No installation or build step is required.

## Project files

- `index.html` contains the page content and the demo workspace.
- `styles.css` controls the design and responsive layouts.
- `script.js` controls the mobile menu, demo signup, and task list.
- [`README-HAP-PAS-HAPI.md`](README-HAP-PAS-HAPI.md) explains how to use the site and understand the code.

## Try the demo workspace

Choose a plan preview, enter a name and valid email address, and open your workspace. There, you can add tasks, mark them complete, filter them, and delete them. Your demo profile and tasks are saved in your browser so they remain after a refresh.

This is a front-end demo, not a real account or subscription service. It does not send or store information on a server, enforce a 14-day trial, send email, or process payments. The $8 per person per month price is sample content only.
